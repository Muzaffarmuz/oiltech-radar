# OilTech Radar 4.0 — мокап-концепт

`oiltech-radar-4.0.html` — единственный файл мокапа. Открывается двойным кликом в любом браузере, без сервера и зависимостей (шрифты подгружаются с Google Fonts, без интернета используется системный шрифт).

Опубликованная копия: https://claude.ai/artifact/6P2dJ8LUEFE8G5CawHL7ua

## src/ — исходники по частям
- `01_head_styles.html` — заголовок и все стили (токены цвета, светлая/тёмная тема)
- `02_body.html` — разметка разделов, шторки настроек и карточки темы
- `03_app.js` — логика: карта, сигналы, прототип «ИТ и автоматизация», наука, инвестиции, компании, онтология, настройки
- `04_policy.js` — раздел «Политика и рынок»: лента внешних событий (санкции, регулирование, инциденты, рынок) со ссылками на источники, экспорт, риск цепочек поставок, матрица влияния, выводы
- `data_proto.json` — снимок реальных данных прототипа 3.1 (portal_data.json от 18.09.2026, сжатый)
- `data_russia_path.txt` — контур России (Natural Earth 50m, коническая проекция) как SVG path
- `data_cities.json` — координаты городов в системе координат карты
- `build.sh` — собирает части в один файл (`sh build.sh` из папки src)

Макетные данные (наука, инвестиции, география, направления кроме ИТ) заданы прямо в `03_app.js` в константах GROUPS, GEO, SOURCES, DEMO_THEMES и функциях renderScience / renderInvest / renderCompanies.
