# OilTech Radar 3.1 — запуск на другом устройстве

Архив содержит код проекта, скачанные статьи (`data/raw`), БД (`data/radar.db`), кэш эмбеддингов, portal JSON и связанные материалы. Папку `.venv` и файл `.env` с секретами **не** включали — их создаёте локально.

## Требования

- Windows 10/11 (или Linux/macOS с аналогом команд)
- Python **3.11+** (`py -3.11 --version`)
- Интернет (установка пакетов + LLM API)
- Ключ API для Astra / OpenAI-совместимого endpoint

## 1. Распаковка

1. Распакуйте архив в удобную папку, например:
   - `C:\Projects\gartner_3.1`
2. Откройте PowerShell в корне распакованного проекта (там, где лежат `README.md` и `requirements.txt`).

## 2. Виртуальное окружение и зависимости

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Если `Activate.ps1` блокируется политикой:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 3. Конфигурация `.env`

```powershell
Copy-Item .env.example .env
notepad .env
```

Обязательно заполните:

| Параметр | Пример | Зачем |
|----------|--------|--------|
| `API_KEY` | ваш ключ | LLM (discover источников, extract, enrich) |
| `BASE_URL` | `https://api.openai.com/v1` или ваш proxy | endpoint |
| `LLM_MODEL` | `gpt-6-astra` или доступная модель | чат-модель |
| `PORT` | `8083` | порт портала |

Остальные поля можно оставить как в `.env.example`.

> Без `API_KEY` портал откроется, но добавление сайтов и полный пайплайн с LLM не заработают.

## 4. Запуск портала

```powershell
.\.venv\Scripts\Activate.ps1
$env:PYTHONPATH = (Get-Location).Path
python -m portal.app
```

Откройте в браузере: **http://127.0.0.1:8083**

Остановка: `Ctrl+C` в терминале.

## 5. Что уже лежит в `data/`

| Путь | Содержимое |
|------|------------|
| `data/radar.db` | SQLite: статьи, события, кластеры, custom sources |
| `data/raw/` | Сырые выгрузки (neftegaz, nprom, sectormedia, angi, oilcapital, comnews…) |
| `data/portal/portal_data.json` | Данные для UI портала |
| `data/cache/` | Эмбеддинги / центроиды (ускоряют повторный запуск) |
| `data/exports/` | Экспорты и доп. материалы |
| `data/runs/` | Логи/QA прогонов |

После первого запуска UI должен показать уже рассчитанные темы без обязательного полного пересчёта.

## 6. Типовые действия в UI

1. **Настройка потока** (справа в шапке) — добавить/выключить/удалить доп. сайты.
2. **Обновить данные** — scrape + пайплайн (включая custom sources).
3. Фильтры: период, компании (мультивыбор), источники (мультивыбор).

## 7. Полезные команды

Проверка API:

```powershell
Invoke-RestMethod http://127.0.0.1:8083/api/status
```

Тесты:

```powershell
$env:PYTHONPATH = (Get-Location).Path
pytest -q
```

Полный пересчёт (долго, нужен LLM):

```powershell
$env:PYTHONPATH = (Get-Location).Path
python -m gartner.pipeline.run --backfill --recluster
```

## 8. Частые проблемы

| Симптом | Что сделать |
|---------|-------------|
| Порт занят | Смените `PORT` в `.env` или завершите процесс на 8083 |
| `ModuleNotFoundError` | Активируйте `.venv`, проверьте `PYTHONPATH` |
| Timeout при добавлении сайта | VPN/прокси, антибот сайта, попробуйте URL ленты `/news` |
| «Источников 0» у custom site | Сайт скачался, но статьи не прошли фильтр профиля (нефтегаз + IT/AI) или пустой текст |
| LLM выключен | Проверьте `API_KEY` и `FORCE_HEURISTIC=0` |

## Контакты по передаче

Перед передачей архива убедитесь, что **не положили** рабочий `.env` с боевым ключом. Получатель создаёт свой `.env` из `.env.example`.
