
```powershell

```


Число кластеров по умолчанию: `min(28, n//35)` — потолок 28, чтобы темы не дробились слишком мелко.

После кластеризации в браузере: **Наука → Новости**, затем Ctrl+F5.

## Lab LLM (креды в скрипте новостей)

В `scripts/cluster_science_news.py` заданы явно:

- `BASE_URL = http://d.dgx:54000/v1`
- `MODEL_NAME = qwen3-32b`

Хост `d.dgx` должен резолвиться в вашей сети (VPN/Lab). Локальный системный прокси на внутренние хосты лучше обходить (`NO_PROXY` скрипт выставляет сам).
