# OilTech Radar 4 — передача проекта

## Быстрый запуск на Windows

1. Распакуйте архив целиком. Не запускайте файлы прямо из окна ZIP.
2. Установите Python 3.11, если его нет. При установке включите Python Launcher (`py`).
3. Дважды щёлкните `УСТАНОВКА.cmd`. Для установки пакетов нужен интернет.
4. Дважды щёлкните `СТАРТ.cmd` и откройте `http://127.0.0.1:8085`.

В архиве уже есть база `data/radar.db` и снимок данных `data/portal/portal_data.json`.
Поэтому сохранённые данные должны отображаться без нового сбора. Файл `.env`
создаётся при установке из `.env.example`. Для простого просмотра API-ключ не нужен.

Для добавления источников и обновления новостного потока укажите собственный
`API_KEY` в `.env` и проверьте `BASE_URL` и `LLM_MODEL`. Это может требовать
доступа к внешним сайтам и платному API. Три будущих потока (наука, инвестиции,
политика) представлены концептуальными экранами; действующий поток —
«Новости и события → ИТ и автоматизация».

Остановка сервера: `Ctrl+C` в окне запуска. Если порт 8085 занят, измените
`PORT` в `.env` и откройте соответствующий адрес в браузере.

Подробности: `ИНСТРУКЦИЯ_для_запуска_на_другом_устройстве.md` и `README.md`.
